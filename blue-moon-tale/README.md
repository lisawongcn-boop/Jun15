# Blue Moon Tale — writing project

Target: a **5,000-word short story**, written at **1,000 words a day over 5 days**, then trimmed to fit each competition.

## Folder map

| File | What goes in it | When |
|---|---|---|
| `01-premise.md` | One-line pitch, theme, genre, ending, which competitions it is for | Day 0 |
| `02-characters.md` | Character sheets (the "character bible") | Day 0–1 |
| `03-setting.md` | Where and when; the rules of the world; the blue moon itself | Day 0–1 |
| `04-outline.md` | The story map: a beat sheet split into 5 parts of ~1,000 words each | Day 1–2 |
| `05-writing-plan.md` | Calendar: which day writes which part, word targets, deadlines | Day 2 |
| `drafts/day-1.md` … `day-5.md` | The actual writing, one file per day | Days 3–7 |
| `06-full-draft.md` | Generated by `combine.py`: all five days joined, with a word count | Day 8 onward |
| `07-revision-notes.md` | What to cut or fix; per-competition versions | Day 8+ |

## Terms you asked about

- **Character building / character bible**: one sheet per character with what they want, what they fear, how they speak.
- **Outline / story map / beat sheet**: the same idea under different names. A list of the story's turning points ("beats") in order. `04-outline.md` uses a 5-part shape so each part is one day's writing.
- **Storyline / arc**: the path a character travels from the first page to the last. The outline shows the plot; the arc shows how the person changes.

## Daily routine

1. Open `04-outline.md`, read today's part.
2. Write into today's `drafts/day-N.md`. Do not edit yesterday's file; forward only.
3. Run `python3 combine.py` to see the running total.
4. Add one line to the log at the bottom of `05-writing-plan.md`.

## Combine and count

```bash
cd blue-moon-tale
python3 combine.py        # writes 06-full-draft.md and prints word counts per day
```
